# 已完成结果

## 实验口径

本页只记录 **6.7 GHz、0° 单波束、560/80/160 场景划分、Multiscale UNO-FM**，
不混入 common8 多波束、跨频率或稀疏 Task 2 结果。

三个阵列使用同一 seed 42 场景划分、相同训练配置、EMA best checkpoint、CFG=1.0、
固定哈希初始噪声和 2-step Euler。以下是一次固定服务器运行的 test-set 结果，不代表
多随机种子均值或置信区间。

## 模型规模

- PyTorch parameter elements：3,059,355（复数参数每个 element 计一次）；
- 独立实标量：3,925,659（每个复数参数计两个实标量）；
- 状态通道：`(32,64,128,256,256)`；
- FNO operator width：24；
- modes：`(12,12,8,4,4)`；
- 共 9 个 FNO stage 与 9 个 CA/SA 条件融合模块。

## 解释边界

- 结果只能说明该固定 split 与单次 seed 下的性能；
- 三个阵列的物理配置和 0° beam ID 由 schema 分别选择；
- 数字不能与多波束、跨频或稀疏重构协议放进同一主表直接比较；
- 若要报告统计显著性，需要额外运行多个独立 scene split/seed。
