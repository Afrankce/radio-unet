# 研究问题：beam map 是否形成条件捷径

**用户确认日期：** 2026-09-05
**状态：** 已批准执行的机制消融问题

## 核心问题

在 6.7 GHz、0° 单波束、每种阵列独立训练的 RadioFlow 多尺度 UNO-FM 中，完整 beam map 是否因为提供了过强的全局辐射模板，使模型优先拟合 beam 的低频空间分布，而没有充分利用 height 学习建筑物附近的遮挡与传播残差？

## 可证伪机制

当前条件为

\[
c=[T,H,B]\in\mathbb{R}^{3\times256\times256},
\]

其中 beam map 既进入原分辨率 lifting，又经条件编码器形成五尺度特征并注入九个 FNO stage。若它确实构成有害捷径，则保持架构和参数量不变、仅令第三通道恒为零后，模型在建筑邻域的误差应当相对开放区域得到更明显改善。

反之，如果 beam map 是有益物理先验，移除后建筑邻域和整体误差均应持平或恶化。若两种变化都小于预先规定的最小实际差异，则认为该固定 0° 单波束协议下 beam map 近似冗余，而不是有害捷径。

## 固定研究范围

- 阵列：8x8、16x16、32x32，分别训练独立模型。
- 频率与波束：6.7 GHz、0° 单波束；beam ID 继续由 manifest/schema 解析。
- 场景划分：560 train / 80 validation / 160 test，固定 `scene_split_seed42`。
- 模型：当前 Attention-Conditioned Multiscale UNO-FM Lite，不改变参数量。
- 消融：训练、验证、测试阶段均使用 `[Tx mask, height, zeros_like(beam_map)]`。
- 推理：EMA、CFG=1.0、固定哈希噪声、2-step Euler。
- 不在看到 beam-zero 结果后改变轮数、区域定义或主判定阈值。

## 不在本次范围内

- 多波束 common8、跨频率和 F3 稀疏重构不混入本次主结论。
- 不把输入物理改成两通道，避免参数量变化造成混杂。
- 不把仅在测试时置零作为主消融；那只能解释已训练模型的输入敏感性。
- 不依据测试结果选择 checkpoint 或调节超参数。
